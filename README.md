# PlayBook

Google Play ブックスを端末標準TTSで読み上げるための Userscript / Android アプリ。

- 目的: 画面オフでも読み上げ継続（Android優先）
- 元: takeshi46/PlayBook の play-books-vertical.user.js
- 本文は個人利用の範囲で、リーダーが表示している内容を読み上げるのみ

## 読み上げ（v1.9.0〜）
バー（☰）の「▶ 読み上げ」で、縦表示の本文を端末標準TTSで読み上げる。読み上げ中の段落を強調し、スクロールと次ページ読み込みに追従。「速度」「声」ボタンで変更（記憶される）。ルビは除いて漢字側を読む。
- 未確認: 実機での動作、画面オフ・バックグラウンドでの継続（止まる場合は Android アプリ化が必要）。
